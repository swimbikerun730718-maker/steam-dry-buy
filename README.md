# STEEM 乾癮商店 🛒

> 玩「買遊戲」的遊戲。用假錢,買真遊戲(的影子),過過乾癮。

**👉 線上遊玩:https://swimbikerun730718-maker.github.io/steam-dry-buy/**

## 玩法

- **商店**:資料每 6 小時自動從真正的 Steam 商店(台灣區、繁體中文)同步 — 熱銷、特價、熱門新品、全球熱銷、即將推出,價格與折扣都是真的。
- **⚡ 限時快閃特價**:每 3 分鐘隨機一款遊戲額外打折,手快有,手慢無。
- **購物車 / 願望清單 / 立即購買**,結帳還有撒花。
- **收藏庫**:按「開始遊戲」掛機(1 秒 = 遊戲內 1 分鐘),依遊戲真實成就數解鎖成就,付費遊戲會掉交易卡片。
- **退款**:遊玩未滿 2 小時可退。
- **打工**:狂點加班賺錢,升職提高時薪與被動收入,每日登入領獎勵,離線也會累積收入(最多 8 小時)。
- **個人檔案**:等級、19 枚徽章(囤積症末期、課長、月光族……)、賣卡片換錢、錢包紀錄。

存檔放在瀏覽器 localStorage。

## 自己跑

```bash
python3 scripts/sync_steam.py   # 抓最新 Steam 資料到 data/store.json
python3 -m http.server 8000     # 開 http://localhost:8000
```

`.github/workflows/sync-steam.yml` 每 6 小時自動同步,也可以在 Actions 頁面手動觸發。
